# 게임 내부 글리프 공급 연결 — v001

2026-09-13. 기존 서체를 유지한 내부 연결 시험판을 만들고, 외부 RAM 수정과 상태 복원 없이 새 부팅에서 출력까지 확인했다. 최신 로컬 빌드는 `03_output/v001_native_loader/`에 있다.

## 연결 구조

MAP의 중·고뱅크 전각 렌더러는 같은 픽셀 처리 루프를 중복하고 있었다. 고뱅크의 원천 주소 계산은 유지하고 공통 루프로 연결했다. 원래 중복 구현이 차지하던 `0x80111034..0x80111297`의 612바이트 안에 75개 명령, 상태값, 캐시 32바이트, 시험 글리프 6개를 넣었다. 확인되지 않은 RAM이나 추가 VRAM을 확보한 방식이 아니다.

새 참조 형식은 `F0 00 47 4C index_lo index_hi`다. 기존 글리프 0x100 다음에 GL 표식과 인덱스가 있는 경우에만 새 경로로 들어간다. 현재 카탈로그의 6개 인덱스를 지원하며, 다른 경우는 기존 경로로 돌아간다. 문자 스트림 포인터의 RAM 범위를 검사해 잘못된 주소를 읽지 않도록 했다.

처음 요청한 글자는 원천에서 캐시 한 칸으로 복사하고, 바로 같은 글자를 요청하면 그 칸을 재사용한다. 다른 글자를 요청하면 같은 칸을 갱신한다. 원래 폰트 1,536칸을 덮어쓰지 않으며, 원래 픽셀 출력 경로를 이용한다. 이 시험의 원천 6자는 MAP과 함께 상주하는 데이터다. CD에서 큰 글꼴 파일을 필요할 때 읽는 공급기는 아직 없다.

## 검증 결과

- 생성한 75개 명령의 종류·레지스터·즉값·분기 목적지를 Capstone으로 검산했다.
- 원래/수정 MIPS 함수를 직접 실행해 기존 글자 및 두 출력 위상의 3,552조건에서 픽셀·배치·보존 레지스터가 일치했다.
- 신규 경로 18조건이 원래 렌더러에 같은 비트맵을 공급한 기준과 일치했다. 잘못된 표식·범위 밖 인덱스·잘못된 스트림 주소의 복귀도 확인했다.
- MAP 전체 정렬 명령과 주소 후보를 검사해 재사용 구간 내부로 들어오는 외부 참조 후보가 없음을 확인했다. EXE·STAYDAT·C_DEMOG·M_BANKS에서도 내부 주소 후보와 새 표식 충돌이 없었다. 이는 동적 간접 참조 전수 증명은 아니다.
- 실제 PS1 코어의 기존 메뉴·맵 5경로 회귀 비교에서 VRAM 전체 차이가 0이었다.
- 서로 다른 두 글자 요청은 캐시 채움 2회, 같은 글자 두 번 요청은 채움 1회·재사용 1회였다. 원래 RAM 폰트는 그대로였다.
- 최종 BIN으로 새 부팅한 3,600프레임 실행에서 '넋뛴'의 화면 픽셀이 원래 서체의 기대값과 일치했다. 외부 RAM 쓰기·세이브스테이트 복원은 없었고, 내부 카운터는 채움 2회를 기록했다.

## 디스크 변경

MAP의 해제 크기는 그대로 373,128바이트다. 재압축 크기는 152,859→153,113바이트로 254바이트 증가했다. 기존 75섹터 안에 들어가므로 LBA·섹터 수를 유지하고 ISO 파일 길이만 갱신했다.

진단 표시를 위해 STAYDAT의 한 UI 문구 앞 12바이트만 새 참조 두 개로 바꿨다. 문장 배치나 종결·제어 바이트는 옮기지 않았다. 이 음절열은 번역문이 아니다. 두 폰트 사본은 변경하지 않았다.

수정 전 섹터 EDC/ECC 재계산 일치, 최종 변경 섹터 허용 목록, ISO 재읽기, LZB 해제 일치, 원본 해시 보존, xdelta 복원 해시 일치를 확인했다. 최종 SHA256은 `505e64ea1429a5994be57a5a57d8c8bcaa93acc53d95892600a152cff3401f23`이다.

최초 빌드 시도에서는 MAP·MOVIE·BATTLE·M_BANKB 네 파일의 압축 왕복을 통과한 뒤, 새 MAP이 이전 파일 바이트 길이를 넘는다는 보수적 게이트에서 멈췄다. 그 결과를 숨기지 않고 동일 섹터 내 크기 갱신을 구현했다. 최종 빌드의 `baseline_lzb_roundtrips`가 빈 배열인 것은 네 검사를 그 호출에서 다시 수행하지 않았기 때문이다. 새 MAP의 왕복·최종 이미지 검사는 최종 호출에서 수행했다.

## 범위와 다음 작업

이번 연결은 **MAP 렌더러에 6자 카탈로그와 캐시 한 칸을 넣은 시험판**이다. 앞선 외부 공급 1,800자 검사를 이 내부 구현의 1,800자 검증으로 합산하지 않는다. 전투 오버레이의 신규 참조 처리, 대용량 원천 글꼴 공급, 캐시 성능과 장면 전환, 장문 삽입은 남아 있다.

시험 코어의 보유 BIOS는 권장 SHA1과 다르다. 지원 BIOS·독립 에뮬레이터·실기 및 전수 플레이는 미검증이다. v001을 완성된 재번역 패치로 사용하지 않는다.
